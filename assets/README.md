# Android App Icon

Jab aapke paas icon ready ho jaye:
1. Apne custom icon ko `icon.png` (1024x1024 pixels, square, transparent background) naam se is `assets/` folder me daal dein (`assets/icon.png`).
2. Capacitor automatically sabhi Android screen resolutions (mipmap) ke liye icons generate kar dega.
3. Abhi ke liye default icon use hoga.
