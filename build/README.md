# Windows App Icon

Jab aapke paas icon ready ho jaye:
1. Apne custom icon ko `icon.ico` naam se save karke is `build/` folder me daal dein (`build/icon.ico`).
2. Electron Builder automatically `build/icon.ico` ko Windows Installer aur Portable .EXE ke icon ke roop me use karega.
3. Abhi ke liye default icon use hoga.
